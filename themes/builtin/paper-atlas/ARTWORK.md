# Paper Atlas artwork

`landscape.png` was generated for this project using the built-in OpenAI image
generation tool on October 3, 2026. It uses no private reference image, character,
brand, or downloaded asset. The original generated file remains in the creator’s
local generated-images directory; the plugin uses this portable copy.

Retained generation brief: a wide original paper-cut mountain landscape and
topographic contours, cotton-paper grain, slate and petrol blue, sand and ivory,
subtle copper paths, two focal anchors at the lower left and upper right, and a
quiet central reading area occupying approximately 45% of the composition. No
text, UI, characters, or brands. This records the retained art direction, not
a byte-for-byte transcript of the earlier tool prompt.
